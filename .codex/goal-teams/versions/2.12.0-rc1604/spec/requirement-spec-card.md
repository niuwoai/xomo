# 需求规格卡：组件覆盖可见性与筛选

## 用户价值

复杂 Figma 组件属性平铺时，用户难以定位哪些值已偏离导入默认值。面板应直接显示覆盖数，并允许只查看本地覆盖后逐项恢复。

## 必须满足

- 标题区显示本地化“已覆盖 n / 总计 m”。
- “仅看已覆盖”默认关闭；开启后仅显示有默认快照且当前属性与默认属性不同的键。
- 无默认快照的属性不计为覆盖，在全部模式仍显示。
- 键顺序稳定排序；无覆盖时显示本地化空态且筛选开关仍可操作。
- 单项重置后该行立即从过滤列表消失；Undo 后重新出现。
- 筛选是纯 UI 状态，不保存到项目，不写 History。

## 不做

- 搜索、一键全部重置、锁定写入修复、精确 TEXT 节点绑定。
- 原生 Xomo 主题保护位与 Figma 属性覆盖的合并。
- 项目格式、导入、同步、渲染和 cursor 改造。
