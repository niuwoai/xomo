# Goal Packet

## 目标

让大型 Figma 组件属性筛选具有明确的可见数/总数反馈，并可一次清除全部本地筛选条件，同时保持 rc1626 的过滤、排序和所有模型协议不变。

## Done Criteria

1. 任一有效筛选激活时显示 `visibleCount / totalCount`；纯空白搜索不激活。
2. 摘要、空态与列表消费同一纯派生结果；三条件仍为 AND。
3. “清除筛选”仅把两个 Toggle 设为 `false` 并清空搜索字符串。
4. 三语 i18n、稳定辅助功能标识、1 个新增动态测试及既有静态合同完整。
5. 版本、CHANGELOG、产品概览与路线图同步；相关串行门禁通过。
6. 独立复审 P0/P1/P2 全部关闭，提交、合入 main、推送并创建 `v2.12.0-rc1627` 标签。

## 禁止范围

- 不修改项目 Codable、Automation、剪贴板、Figma 导入、组件选择或 cursor。
- 不修改属性覆盖/诊断/搜索规范化语义。
- 不执行 Release 或 `/Applications` 覆盖；下一个 40 版本门禁是 rc1640。
