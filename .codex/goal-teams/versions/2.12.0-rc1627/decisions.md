# Decisions

| ID | 决策 | 理由 |
| --- | --- | --- |
| D-01 | 总数固定为当前选中图层完整组件属性数 | 避免把覆盖数、诊断数或中间筛选基数混作总数 |
| D-02 | 有效搜索采用既有固定 locale 规范化后的非空结果 | 纯空白输入不应产生筛选状态 |
| D-03 | 新增纯 `FilterResult` 快照，旧 keys API 委托它 | 摘要、空态和列表共享唯一语义，保留兼容入口 |
| D-04 | 清除动作留在 `ImageEditorView` 本地状态 | 不把 UI 偏好写入 ViewModel、Document 或 History |
| D-05 | `m/m` 与 `0/m` 都显示摘要 | 用户始终能看见筛选仍处于激活状态 |
| D-06 | 保留搜索框原有单独清除按钮 | 区分“只清搜索”和“清除全部筛选” |
