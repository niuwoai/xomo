# Requirement Specification Card

## 核心目标

当用户组合使用 Figma 组件属性的覆盖、诊断和搜索筛选时，明确显示最终结果数量，并能一次恢复未筛选状态。

## 用户流程

1. 用户开启任一 Toggle 或输入 trim 后非空搜索。
2. Inspector 显示“当前显示 n / 共 m 个属性”与“清除筛选”。
3. 列表、摘要和空态来自同一过滤结果；即使 `n == m` 或 `n == 0` 仍显示摘要。
4. 用户点击“清除筛选”，两个 Toggle 关闭、搜索清空、完整列表恢复，摘要与按钮消失。

## 边界

- 纯空白搜索不激活。
- 搜索框 `×` 继续只清搜索；新按钮清全部三个条件。
- 不修改属性、项目、History/Undo、Automation、剪贴板、导入、选择或 cursor。
