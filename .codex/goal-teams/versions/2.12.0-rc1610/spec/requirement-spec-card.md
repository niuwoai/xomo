# rc1610 Requirement Spec Card

## 用户价值

用户在使用顺/逆时针 90°、180°、水平翻转和垂直翻转时，Fireworks 风格热点必须与图像内容同步，不再留在旧画布坐标。

## 行为契约

- 以变换前的 `document.canvasSize` 为唯一源坐标域。
- 五种正交变换均为双射：热点一对一保留，不裁切、不删除、不重排。
- 只改变热点 `frame`；`id`、`name`、`url`（包括首尾空白）原样保留。
- 90° 旋转交换画布和热点宽高；180° 与翻转保持画布尺寸。
- 有效热点选择保持，`nil` 保持 `nil`；陈旧的非空选择回退首个热点，空列表回退 `nil`。

## 几何契约

设旧画布为 `W × H`，源热点标准化后为 `(x, y, w, h)`：

| 操作 | 目标 frame | 目标画布 |
| --- | --- | --- |
| 顺时针 90° | `(H-y-h, x, h, w)` | `H × W` |
| 逆时针 90° | `(y, W-x-w, h, w)` | `H × W` |
| 180° | `(W-x-w, H-y-h, w, h)` | `W × H` |
| 水平翻转 | `(W-x-w, y, w, h)` | `W × H` |
| 垂直翻转 | `(x, H-y-h, w, h)` | `W × H` |

源画布与 frame 必须有限、正尺寸并完全位于源画布；负宽高先标准化。先进行完整浮点变换，再对最终矩形执行一次 `.integral`。零面积、NaN、无穷、溢出或越界数据使整次命令失败。

## 范围边界

本版不处理任意角度旋转、Slice、普通选区、保存选区、Alpha 通道、参考线、保存路径、schema 或新 UI。上述现有画布空间一致性缺口进入后续相邻里程碑。
