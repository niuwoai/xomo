# 2.12.0-rc1610 Decisions

- 顺/逆时针 90°、180°、水平和垂直翻转是非破坏性双射，热点数量不得减少。
- 热点使用与现有图层 frame 相同的坐标公式；90° 交换宽高与画布宽高。
- 存活热点保持身份、名称、URL 与相对顺序；选择态保持有效 ID 或 nil。
- 所有热点变换在 `pushUndo()` 前预计算，损坏或越界源几何整次拒绝。
- 原始 frame 先校验有限值，再标准化；对变换后的完整矩形只执行一次向外整数化，并再次验证目标边界。
- 成功提交后同步尺寸控件，保持既有画布视口偏移；失败除状态文本外不得修改文档、历史、Undo/Redo、选择或面板状态。
- 任意角度、Slice、selection/channel/guide 的额外能力与 schema 变化留到后续小版本。
