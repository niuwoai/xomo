# 需求规格卡：响应式 HTML 热点坐标

## 用户价值

导出的热点页面在手机、小窗口和响应式容器中仍能点中视觉上对应的区域，而不是停留在原始大图坐标。

## 必须满足

- `<area coords>` 保留导出时像素值作为回退。
- 每个 area 保存可信的源坐标数据，图片保存可信的源画布宽高。
- 页面脚本只读取这些数值并按实际显示尺寸重算坐标。
- 宽高独立缩放，支持非等比容器尺寸；结果使用整数。
- 脚本在图片已缓存、后加载、窗口调整和元素尺寸变化时都可同步。
- 热点 href 只允许 HTTP(S)、邮件、电话及安全相对/片段地址，危险或未知协议回退 `#`。

## 不做

- 不新增 hotspot responsive flag、anchor、constraint 或 normalized frame。
- 不修改编辑器内热点坐标、项目 Codable、Automation 输入输出或 UI。
- 不扩展切片，不改变画布 resize/crop/rotate/flip 语义。
