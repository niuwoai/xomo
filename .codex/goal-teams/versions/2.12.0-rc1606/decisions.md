# 2.12.0-rc1606 决策

| 日期 | 决策 | 理由 |
| --- | --- | --- |
| 2026-09-05 | rc1606 只修 HTML 导出后的运行时热点缩放 | 直接解决真实错位且无需扩项目、UI 或 Automation |
| 2026-09-05 | 保留原始像素 coords 作为无脚本回退 | 渐进增强，不让脚本成为链接可用性的唯一条件 |
| 2026-09-05 | 用户内容不进入脚本 | 名称、URL、标题只经既有 HTML 转义路径输出，降低注入风险 |
| 2026-09-05 | 热点链接采用协议白名单 | HTML 转义不能阻止 `javascript:`；危险或未知协议必须回退 `#` |
| 2026-09-05 | 持久化响应式模式与完整画布几何闭环后置 | 两者都会触及多个消费者或项目兼容，不适合本小版本 |
| 2026-09-05 | cursor 不变 | 导出层能力不应影响编辑器指针语义 |
