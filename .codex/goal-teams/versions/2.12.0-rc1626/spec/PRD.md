# PRD

## 目标

在 rc1625 的组件属性健康筛选之上增加轻量本地搜索，让大型 Figma 组件的属性定位更快，同时保持既有编辑、诊断、Automation 与项目格式合同不变。

## 用户流程

1. 用户选中含 Figma 组件属性的图层，在 Inspector 的组件属性区域输入查询。
2. 列表保留属性 key 或当前 `property.value` 包含查询文本的属性。
3. 若同时启用“仅看已覆盖”或“仅显示有问题”，搜索结果继续与这些条件取交集。
4. 用户清空查询后恢复由两个既有筛选决定的列表；两个筛选也关闭时恢复全部属性。

## 搜索语义

1. 匹配字段固定为属性 key 与当前保存的原始 `property.value`，任一字段命中即可保留。
2. 匹配方式为包含匹配，而非前缀、完整相等、正则或模糊纠错。
3. 查询先移除首尾空白与换行，再按忽略大小写和变音符号的文本比较执行匹配。
4. 修剪后为空的查询视为搜索未启用，不过滤任何属性。
5. 不解析 Boolean、数字、实例引用等类型；所有当前值统一按现有字符串表示匹配。
6. 不匹配属性 `type`、诊断代码/文案、preferred values 的未选候选项或候选显示名。

## 组合筛选与排序

1. 可见条件为 `searchMatch && overrideMatch && diagnosticMatch`；未启用的条件恒为真。
2. 搜索、仅覆盖、仅问题三者可任意组合，不采用逻辑或，也不让任一条件覆盖另一条件。
3. 所有组合的最终 key 都按既有 key 排序规则稳定排序；查询文本不得改变排序权重。
4. 搜索启用且结果为空时显示通用筛选空态；既有筛选单独造成空结果时也继续显示该空态。

## 状态与副作用

1. 查询状态只存在于当前 Inspector 视图生命周期，不编码到文档、项目、图层或应用偏好。
2. 输入、修改、清空查询均不修改文档，不产生 History/Undo/Redo 项，不改变项目 dirty state。
3. 搜索不改变属性健康计数与覆盖计数；摘要始终描述完整属性集合，而不是当前可见子集。
4. 搜索不改变复制全部、复制覆盖、粘贴覆盖、单项还原、全部还原和属性写入的作用域。
5. 搜索不改变任何 Automation action、请求/响应 schema 或根级健康计数。

## 交互与可访问性

1. 搜索输入与搜索造成的空态使用三语 i18n 文案，不硬编码用户可见文本。
2. 搜索输入和空态提供稳定 accessibility identifier，供自动化定位。
3. 搜索框聚焦期间，普通文字与输入法输入必须由文本框接收，不能触发画布工具单键快捷键。
4. 本里程碑不规定新的全局快捷键，不改变既有工具、组件库或画布 cursor 行为。

## 验收标准

1. 大小写不同仍可命中 key 和 value，例如查询 `label` 可命中 `Label`。
2. 查询两端含空白或换行时，与修剪后的查询结果一致。
3. 变音符号不影响匹配，例如无重音查询可命中带重音文本。
4. 空字符串或纯空白查询返回与未搜索相同的结果。
5. key 命中与当前 value 命中都有效；候选显示名或未选候选值不会单独造成命中。
6. 搜索与仅覆盖、仅问题形成三重 AND，所有组合结果正确且稳定按 key 排序。
7. 任意已启用筛选造成无结果时显示本地化空态；无筛选且属性存在时不显示空态。
8. 搜索不会改变完整集合的覆盖数、问题数或阻塞数，也不会改变编辑与 Automation 合同。
9. 搜索输入不持久化，不写项目，不进入 History/Undo/Redo，且聚焦输入不误触画布工具快捷键。

## 非目标

- 不实现正则、模糊匹配、搜索高亮、排序相关性或搜索历史。
- 不搜索类型、诊断、候选值目录、候选显示名、默认值或 Figma 云端元数据。
- 不持久化查询，不修改项目格式、导入协议、Automation、剪贴板或 cursor。
- 不实现真实 `INSTANCE_SWAP`、Figma 云端同步或跨图层全局搜索。
