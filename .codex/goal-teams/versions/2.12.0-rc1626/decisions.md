# Decisions

- 搜索采用属性 key 或当前原始 `property.value` 的包含匹配；两者任一命中即满足搜索条件。
- 查询先修剪首尾空白与换行，再忽略大小写和变音符号比较；修剪后为空等同未启用搜索。
- 搜索不匹配类型、诊断、默认值、未选候选项或候选显示名，避免结果随编辑器类型或本地化语言漂移。
- 可见行采用 `搜索 && 仅覆盖 && 仅问题`；未启用条件视为真，结果沿用 key 稳定排序，不做相关性重排。
- 查询仅是 Inspector 当前生命周期内的视图状态，不写项目、图层或用户设置，不进入 History/Undo/Redo，也不改变 dirty state。
- 搜索只控制行可见性；摘要计数与复制、粘贴、还原、写入和 Automation 继续作用于既有完整合同。
- 搜索框聚焦时由标准文本输入消费普通键入，不新增全局快捷键，也不改变组件库选择与 cursor 语义。
