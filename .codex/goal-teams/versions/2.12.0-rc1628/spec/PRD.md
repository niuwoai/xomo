# PRD

## 问题

Inspector 直接显示 `TEXT` 等机器类型，辨识成本高；未知与空白协议值又必须保真，不能被友好文案掩盖。

## 方案

在每项属性值旁展示紧凑只读徽标。标准类型使用本地化产品名称，未来未知类型显示 raw，空白类型显示未知兜底；悬停说明始终给出原始 Figma type。

## 验收

- 四个标准值只做精确匹配并三语显示。
- `text`、` Text `、未来类型保持 raw；空串和纯空白使用未知文案。
- raw type 不被 trim 或改写，Codable 往返相等。
- 属性搜索仍只命中 key/current value。
- 徽标没有写入、还原、Binding 或焦点行为。
