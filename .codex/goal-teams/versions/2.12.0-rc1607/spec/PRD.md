# PRD：Image Size 保持热点对齐

## 功能需求

1. Image Size 改变整张图像与画布采样尺寸时，所有热点按相同横纵比例变化。
2. 热点缩放属于 Image Size 的同一原子事务，不产生逐热点历史记录。
3. 无变化、非法目标尺寸或非法热点不能留下半更新状态。

## 验收标准

- `100×80 → 250×120` 时 `(10,8,20,16)` 变为 `(25,12,50,24)`。
- 多热点的身份、元数据与数组顺序完全保留。
- 完整项目编码在 Undo 后等于操作前、Redo 后等于操作后。
- Automation 调用共享同一 ViewModel 路径并返回缩放后的热点坐标。
- HTML 导出、项目往返和组件库系统箭头合同不回归。
