## 组件库

组件库与工具箱共用左侧区域。点击“组件库”标签后，可选择主题并插入按钮、表单控件、内容模块、导航、列表和选择控件。

![组件库面板](assets/interface/component-library.png)

- 单击组件卡片：插入到默认位置。
- 拖动组件卡片：放到画布指定位置。
- “插入当前主题页面示例”：一次生成完整页面结构。
- “应用到所选组件”：把当前主题应用到选中的组件实例。
- “保留局部样式”：主题同步时保留用户修改过的局部值。
- 主组件、链接、同步和脱离用于管理多个组件实例。

## 图层面板

一个新画布通常包含锁定的背景层和一个可编辑像素层：

![基础图层面板](assets/interface/layers-panel.png)

插入组件后，组、文字与形状会分别出现在图层列表中：

![包含组件的图层面板](assets/interface/layers-with-components.png)

### 顶部操作

| 控件 | 作用 |
|---|---|
| `+` | 新建透明像素图层 |
| 图片加号 | 导入图片为图层 |
| 文件夹加号 | 新建图层组 |
| 复制 | 复制当前图层 |
| 上/下箭头 | 调整图层顺序 |
| 圆形虚线 | 添加图层蒙版 |
| 垃圾桶 | 删除图层 |
| 更多 | 打开高级图层操作 |

### 每个图层行

- 最左侧眼睛：显示或隐藏图层。
- 拖动手柄：改变层级；拖到组的有效区域可加入图层组。
- 缩略图和名称：说明内容类型。
- “文字”“形状”“组”等标签：说明图层结构。
- `100%`：当前图层不透明度。
- 锁：控制图层是否允许编辑。

图层列表支持搜索，可按名称、类型、标签或状态过滤。眼睛位置只控制可见性，不删除内容。

### 选择多个图层

- 普通点击：只选择当前图层，并把它设为后续连续选择的锚点。
- `Command` 点击：在现有选择中单独加入或移除一个图层。
- `Shift` 点击：选择锚点与目标之间的连续图层；再次 `Shift` 点击可沿原锚点向上或向下调整范围。
- `Command+Shift` 点击：把锚点到目标的连续范围追加到已有的不连续选择。

连续范围按图层面板当前真正显示的行计算。使用搜索、类型过滤或折叠图层组后，面板里看不见的图层不会被悄悄选中。清除图层选择后，下一次 `Shift` 点击会从新目标重新建立锚点。

多选后，点击任一已选行的眼睛、总锁、像素锁、位置锁或透明像素锁，会把整个选择集合统一到目标状态。例如点击一条当前可见的已选图层，其全部已选图层都会隐藏；点击隐藏行则统一显示。点击未选中的图层行控件仍只修改该行，不会清掉或误改当前多选。文字等不支持透明像素锁的图层会被自动跳过。

### 调整图层顺序

- 选择图层后，使用面板顶部的上/下箭头，或“图层”菜单中的上移、下移、置顶和置底命令。
- 顺序命令以面板当前显示的行作为依据。搜索或过滤后，隐藏的非匹配图层会被跳过；例如只搜索“按钮”时，上移会移动到上一个可见的“按钮”位置。
- 折叠的图层组会连同所有子层和嵌套组一起移动，组内相对顺序不会散架。
- 展开组时，把外部图层向下越过组标题会进入该组；组内最上方图层向上越过组标题会离开该组。
- 多选时，不连续的可见区段会同步移动；一次命令只产生一个 History 步骤，因此一次撤销即可恢复整批图层的原始层级和顺序。

拖动图层行也使用同一套层级规则：放到组内部会加入该组，放到其他行上方或下方会按完整子树重排；不允许把父组拖进自己的后代组。

### 编组与解组

- 选择两个或更多同级图层后执行“从所选图层建立组”，Xomo 会保持它们原来的前后关系，并把原本不连续的所选项整理成一个连续子树。新组放在最高所选项原来的层级位置并自动展开。
- 如果同时选择父组和其中某个后代，显式选中的后代会提升为新组的直接成员，且不会复制；父组中没有单独选中的其余后代仍保持原来的嵌套结构。
- 锁定图层或受锁定父组影响的图层不会被移动，但会留在原位置并保持选中。可编辑的其余所选项仍可完成编组。
- 没有共同所选祖先、分别属于不同父组的图层不能在一次操作里强行编组；应先移动到同一层级，或把共同祖先一并选中。
- “解组所选组”可一次处理多个组，包括同时选中的父组和嵌套子组。成员会提升到最近仍存在的父级；锁定组、无关图层及其选择不会丢失。
- 折叠组可以直接解组，解组后成员立即显示。编组或解组整批操作都只记录一个 History 步骤，按一次 `Command+Z` 即可恢复原顺序、父级、折叠状态和选择。

### 移入与移出图层组

- “移入上方图层组”以图层面板中当前选择上方、同层级的下一个可编辑组作为目标。所选普通图层和所选组的完整子树会保持相对顺序，连续放到目标组的最上方；目标组会自动展开。
- 不连续多选会被收拢到同一目标组，但锁定项仍留在原位置并保持选中。如果可编辑所选项原本属于不同父级，命令不会猜测意图或破坏树结构，此时应先把它们移动到同一层级。
- “移出图层组”把所选根及其完整子树放到原父组正上方。一次选择跨越多个组时，每个分支使用自己的原父组边界；嵌套组成员会提升一级，而不是一律扔到画布最外层。
- 同时选中父组和它的后代时，完整子树只移动一次。锁定项会被跳过，选择和主选择仍保留。
- 移入、移出都会形成一个 History 步骤；一次 `Command+Z` 可恢复原顺序、父级、目标组折叠状态和选择。

选中包含透明占位成员的组时，变换框会使用这些成员的图层范围作为兜底，因此仍可用移动工具整体拖动，不会因为“没有可见像素”就像空气一样抓不住。

### 快速展开与折叠图层组

- 直接点击图层组的展开箭头：只展开或折叠当前组。
- 按住 `Option` 点击展开箭头：递归展开或折叠当前组以及其中所有嵌套组。
- 选择一个或多个图层组后，可从“图层”菜单或面板“更多”菜单执行“展开所选组”“折叠所选组”。这两个命令会递归处理每个所选组的完整分支。
- 折叠后如果原选择位于被隐藏的组内，Xomo 会选中可见父组；原本仍可见的其他选择不会丢失。

展开与折叠只改变面板视图，不改变图层内容和结构，因此不会增加 History 步骤，也不需要撤销。

## 通道面板

点击“通道”标签可查看 RGB、红、绿、蓝、Alpha 和自定义 Alpha 通道。

![通道面板](assets/interface/channels-panel.png)

每个通道提供三类操作：

1. 点击通道名称预览该通道。
2. 点击虚线圆图标，把通道亮度载入为选区。
3. 点击保存图标，把当前通道保存为新的 Alpha 通道。

通道预览只改变观察方式；正常导出仍使用完整合成图。

## 复合

“复合”标签用于记录或切换图层组合状态。它适合比较不同可见性、位置和样式方案，例如同一页面的登录态/未登录态或浅色/深色方案。

建议先给复合状态清晰命名，再修改图层。恢复复合时会回到被记录的组合状态。

## 导航器与信息

![导航器与历史区域](assets/interface/navigator-history-panels.png)

- 导航器显示画布缩略图和当前可见范围，适合在高倍率下快速定位。
- 信息区域显示尺寸、指针坐标、颜色取样和直方图等辅助数据。
- 导航器不应盖住画布内容，也不会遮挡画布右上缩放工具条。

## 历史面板

![历史面板](assets/interface/history-panel.png)

每次有效操作都会生成一个历史步骤，例如建立选区、新建文字、盖印可见图层或仿制图章。

- 单击历史步骤：选中该步骤。
- 点击步骤旁的恢复按钮：把文档恢复到该状态。
- 选中某一步后按 `Delete`：从该步骤开始截断后续操作；第一步不能删除。
- `Command+Z`：撤销一步。
- `Command+Shift+Z`：重做一步。
- `Option+Z`：同样可执行撤销。

命名快照与普通历史不同：快照用于长期保留一个状态，可恢复、复制、重新排序或删除，不会随着普通撤销链一起消失。
