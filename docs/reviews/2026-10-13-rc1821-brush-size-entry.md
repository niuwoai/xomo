# rc1821 画笔尺寸精确输入验证

- 日期：2026-10-13
- 分支：`codex/brush-size-precise-entry-rc1821`
- 起始基线：`7df84d9f`（rc1820 已合入 main）
- 目标：解决大范围尺寸滑块精度不足的问题，让用户能直接键入 1–512 px 之间的精确画笔直径。

## 实现

- 画笔尺寸选项栏把原只读尺寸文本换成数字输入框，复用已有“尺寸”本地化标签，并继续显示 px 单位。
- 键入值仍写入同一个 `brushSize` 绑定，由 ViewModel 归一化并持久化；下限/上限仍为 1–512 px。
- 参数仅对画笔尺寸滑块开放，硬度、不透明度及其他工具的数值读数保持原只读显示。
- 输入框提供稳定辅助功能标识，便于 UI 测试和辅助技术定位。

## 验证

- `ImageEditorScopeTests`：200/200，包括 257 px 精确值、900 px 夹取至 512 px、已存在的越界边界与源接线检查。
- `LocalizationResourceTests`：46/46，确认复用标签仍有完整本地化资源。
