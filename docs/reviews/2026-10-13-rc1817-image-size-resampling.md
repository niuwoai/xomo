# rc1817 图像尺寸重采样

## 目标

图像尺寸调整原先固定走 AppKit 默认插值，像素画被放大时容易出现模糊边缘。rc1817 在「图像尺寸」控件中提供最近邻与平滑两种模式：最近邻适合像素画，平滑适合照片和渐变。默认值仍为平滑，以保留此前通用缩放行为。

## 实现范围

- 图像尺寸命令通过同一模式重采样栅格图层内容、图层栅格蒙版、后滤镜裁切蒙版和 Alpha 通道。
- Alpha 通道平滑模式执行双线性覆盖插值；图像和 NSImage 蒙版选择 AppKit 的 `.none` 或 `.high` 插值质量。UI 使用“平滑”而非声称图像采样核必定是双线性。
- 选区与已保存选区继续使用既有几何投影/最近邻语义；文字、形状、矢量蒙版、切片、热点和参考线沿用各自几何缩放规则。画布尺寸命令不受影响。
- 一次 Image Size 仍只推入一次 undo，History/Undo/Redo 数据往返保持原流程。

## 验证

- `ImageEditorSliceImageSizeTransformTests`：9/9 通过。新增 8×8 红/蓝硬边图放大至 16×16：最近邻输出只保留源色，平滑输出包含过渡色；Alpha 通道按相同模式保留二值或产生中间覆盖值；Undo/Redo 往返与单事务断言通过。
- `LocalizationResourceTests`：46/46 通过，检查简体中文、英文、日文资源键一致及打包值一致。
- Release Contract 10/30、CLI Release Contract 7/24、Product Overview Archive 3/30 与 isolated test runner contract 通过；`git diff --check` 通过。
- 首次测试尝试使用 2×1 画布，低于编辑器最小画布尺寸，Image Size 按预期拒绝输入；将测试夹具修正到有效尺寸后，回归通过。这是测试夹具问题，不是产品缺陷。
- 最终源码改动后重新构建并运行上述 9 项图像尺寸套件，通过；本记录不将其描述为 rc1840 的完整 Release 构建、全量测试、桌面冒烟或 `/Applications` 安装验收。
