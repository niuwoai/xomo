## 正确性边界

- 不缓存“已干净”布尔值，不依赖可变 NSImage 身份。匹配元数据时仍重新编码所有实际 PNG、蒙版、智能对象源及既有图像填充负载。
- 精确校验选区坐标位模式及有限性、布尔值、栅格尺寸/alpha；通道名字比较 UTF-8，而非 Unicode 规范等价。负零、不同 Unicode 标量或任何不能证明等价的排除字段回退完整项目字节比较，不直接判干净。
- 其余字段包含图层复合、历史、主题、采样设置与全部图像数据，继续重新编码逐字节比较。旧 full-data-only 基线保留回退，清空和编码失败保守判脏。
- 保存检查点在 writer 前与实际写入 DTO 配对；writer 内再次编辑不推进到未写入内容。状态和接口移到独立小文件，未改变 Undo/Redo 事务、外部导入或项目格式，未扩张 Figma。
