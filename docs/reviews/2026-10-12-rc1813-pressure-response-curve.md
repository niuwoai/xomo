# rc1813 压力响应曲线

## 目标

为经典绘画工作流提供可选的轻触/重压响应，同时让旧项目与既有笔触保持原有线性响应。范围仅限 Brush、Pencil、History Brush、Eraser，以及这些工具共享的快速蒙版、画笔光标和喷枪预览；修图笔刷继续使用原来的映射。

## 实现

- 将响应曲线与原有压力敏感度指数相乘：线性为 `1.0`，轻触为 `0.7`，重压为 `1.4`。
- 工作区偏好和用户自定义笔刷预设存储曲线；旧 JSON 缺字段时按 `.linear` 解码。
- 工具选项菜单提供三种本地化选择；光标直径与画笔笔触共享同一压力映射。
