# rc1758 Display P3 PDF 导出像素验证

## 用户工作流

最近的色彩交付回归已覆盖普通 PNG、JPEG、WebP 和 PSD，但普通 PDF 只有格式可生成断言，没有验证 P3 源图在 PDF 阅读器中的可见颜色。新增回归从 Display P3 像素生成 PDF，再将实际 PDF 页面栅格化到 sRGB，按颜色管理后的参考值逐通道比较；同时验证导出不修改编辑历史或图层选择。

## 实际验证

- `ImageEditorExportFormatTests/displayP3PDFExportPreservesColorWhenRenderedToSRGB`：build-for-testing 成功，1/1 实际测试通过。
- 1×1 P3 `[200, 120, 40, 255]` 导出为单页 PDF；页面读回到 sRGB 后 RGB 每通道与 P3→sRGB 参考值相差不超过 2，Alpha 为 255。
- 导出前后 History 与选中图层集合一致。
- `scripts/test_release_contract.rb`：10 runs / 30 assertions 通过。
- `scripts/test_xomo_cli_release_build.rb`：7 runs / 24 assertions 通过。
- `scripts/test_product_overview_archive.rb`：3 runs / 26 assertions 通过。
- `scripts/verify_release_contract.rb`：通过；App、CLI 与 Xcode 六配置版本为 `2.12.0-rc1758` / build `1758`。
- `git diff --check`：通过。

本版测试确认既有 PDF 编码路径在该 P3 像素场景保持颜色，因此没有更改生产编码。该测试证明 Core Graphics PDF 页面读回的一致性，不替代外部 Photoshop/Acrobat 版本、打印机 ICC 流程或全量 Release 门槛；真实应用冒烟、全量构建和 `/Applications` 覆盖安装仍留待 rc1760。
