# rc1822：自定义 Cube LUT 输入域

## 用户影响

`.cube` 的 `DOMAIN_MIN` / `DOMAIN_MAX` 描述源 RGB 如何映射到 LUT 网格。旧实现跳过这两项，却仍接受文件，导致非默认输入域的 LUT 被按 0–1 采样并产生错误色彩。现在先按各通道声明域归一化输入、夹到网格边界，再做既有三线性插值；输出采样和透明度行为不变。

域范围保存在 `ImageEditorColorLookupCube`，因此会随调整层项目数据持久化。旧项目没有这两个字段时按标准 `[0, 0, 0]... [1, 1, 1]` 解码。非有限、倒置/相等或只声明一端的域会被拒绝，避免静默生成错误颜色。LUT 网格最大维度仍限制为 64。
