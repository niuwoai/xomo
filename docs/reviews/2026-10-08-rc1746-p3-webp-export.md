# rc1746 Display P3 WebP 导出验证

## 目标

普通导出和 Layer Comp 导出都提供 WebP，但此前直接把复合图像交给 ImageIO，未像 JPEG 一样显式转换色彩空间。广色域样本可能随编码器 profile 解释产生偏色。本版将两条 WebP 路径改为复用 sRGB 有损位图编码，并保留 WebP alpha；JPEG 继续沿用同一编码实现并保持白底扁平化。

## 实现与边界

- `ImageEditorExport.swift` 的 `exportData` 对缩放后的 WebP 图像先归一化到 sRGB；Layer Comp WebP 同样显式归一化。
- `lossyBitmapData` 统一通过 sRGB CGContext 和 ImageIO 编码 JPEG/WebP。只有 JPEG 调用白底扁平化；WebP 保留透明像素。
- `ImageEditorJPEGExportColorTests.swift` 直接将 Display P3 CGImage 放入文档图层，避免外部导入工厂提前归一化而掩盖导出行为。检查普通 WebP 0.5× 8×8、Layer Comp WebP 16×16 的解码 profile、sRGB 颜色、约 50% Alpha，以及导出前后 History/选择不变。
- 本版只证明本机 ImageIO WebP 编码器路径；没有验证其它 macOS 版本、第三方解码器显示、PDF 或所有 ICC profile，不宣称完整色彩管理。
