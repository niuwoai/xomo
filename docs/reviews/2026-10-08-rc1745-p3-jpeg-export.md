# rc1745：广色域 JPEG 导出

## 范围与基线

- 基于已集成 rc1744 的本地 `main`（`2bae8568`），开发分支 `codex/p3-jpeg-export-rc1745`。
- 普通 JPEG 与 Layer Comp JPEG 统一走 ImageIO JPEG 编码；输出画布使用明确的 sRGB CGContext，透明像素按既有白底语义合成。
- 普通导出按设置 scale 直接绘制到目标像素尺寸，避免先经 AppKit DeviceRGB 缩放再编码；ImageIO 编码保留 sRGB profile。

## 验证

- `ImageEditorJPEGExportColorTests`：1/1 通过。Display P3 不透明图像缩放为 8×8 后，JPEG 解码 profile 为 sRGB，RGBA 与同文档 Quick Export PNG 的 sRGB 像素参考在 JPEG 容差内一致。
- 半透明 P3 样本导出 JPEG 后与白底 alpha 合成参考一致；Layer Comp JPEG 解码也保留 sRGB profile，像素与 P3→sRGB 参考一致。
- 原有 `imageEditorExportsCompositeAndCurrentLayerWithFormatSettings`：1/1 通过；JPEG 签名仍为 `FF D8`，80×60 图像以 0.5× 导出仍为 40×30。
- 版本合同 10 runs/30 assertions、CLI release build contract 7 runs/24 assertions、产品概览归档合同 3 runs/26 assertions 全部通过；`scripts/verify_release_contract.rb` 确认 App/CLI `2.12.0-rc1745`、Xcode 六配置与 build number `1745` 一致；`git diff --check` 通过。
- JPEG 采用有损编码，测试按色差容差比较；sRGB profile 名称、实际解码颜色和 PNG 对照均分别检查。

## 限制与下一步

- 未在 Photoshop 等外部应用验证显示效果；未覆盖 PDF、WebP 或非 sRGB ICC 输入组合，本版不宣称全格式色彩管理。
- 未运行 rc1760 四十版本完整构建/全量回归/界面冒烟/可恢复安装门槛；当前安装版记录为 rc1729。
