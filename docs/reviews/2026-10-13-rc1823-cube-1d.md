# rc1823：1D Cube LUT 导入

## 用户影响

外部 `.cube` 既可以存储 1D RGB 通道表，也可以存储 3D RGB 表。Xomo 原先只解析 3D `LUT_3D_SIZE`，有效的 `LUT_1D_SIZE` 文件无法用于 Color Lookup。现增加 1D 表解析和按通道线性插值，并复用已有的调整层和自定义 Cube 导入入口。

每个通道独立映射其声明的输入域，再在线性相邻采样点间插值。表类型与采样点数持久化到调整层；旧项目缺少 1D 字段时仍识别原有 3D Cube，旧域字段继续默认为标准域。属性栏与导入状态现在显示正确的 1D 采样点数或 3D 维度。

`DOMAIN_MIN` 与 `DOMAIN_MAX` 可分别省略；缺失项采用规范默认值。代码维持现有 3D LUT 64³ 资源上限，1D LUT 限于规范定义的 65,536 点。这里实现 1D 或 3D 表文件，不接受同一文件同时声明两种表。
