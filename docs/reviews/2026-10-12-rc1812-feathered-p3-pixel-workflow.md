# rc1812 羽化选区 P3 像素编辑闭环

## 范围

为现有 P3 导入 → 矩形像素选区 → 移动 → 撤销/重做 → 项目重开 → 导出工作流补上羽化选区场景。测试使用带 Display P3 profile 的 PNG 夹具，先羽化 2 px，再移动选区像素。

本版只补齐跨功能集成回归，不改变选区、像素变换、项目编码或导出算法，也不宣称完成完整 GUI/Release 门槛。

## 验证

- 直接确认羽化蒙版同时包含 0、255 之间的半透明覆盖值。
- 移动后的图像像素与羽化前不同；Undo 恢复羽化后的完整项目数据，Redo 恢复移动后的项目数据。
- 保存重开后合成像素保持一致；导出 PNG 的颜色空间为 sRGB，RGBA 与重开项目的合成结果逐字节一致，导出不会改变历史。
