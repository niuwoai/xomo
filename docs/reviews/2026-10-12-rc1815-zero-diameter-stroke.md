# rc1815 零压力与零最小直径

## 用户影响

rc1814 将零压力映射为零，但画笔栅格器仍把零直径提升到 1 像素半径，导致仅启用压力控制大小、且最小直径为零时留下单像素。现在零尺度 stamp 不参与覆盖累积；当用户将最小直径设置为非零值时，该下限仍正常生效。修复位于共享画笔覆盖内核，包含像素笔迹、图层/快速蒙版及复用该内核的压感修图遮罩。

## 验证

- 修复前新增零压力/零最小直径像素测试失败：透明源 PNG 与输出 PNG 不同，证明旧路径实际产生像素。
- 修复后 `ImageEditorBrushStrokeTests`：62/62，通过；零压力/零最小直径输出与透明源 PNG 完全一致，零压力下显式非零最小直径仍产生笔迹，既有尺寸/覆盖行为保持通过。
- 发布合同：10 runs / 30 assertions；CLI Release Build 合同：7 / 24；产品概览归档合同：3 / 30；隔离测试器合同与 `git diff --check` 通过。
- 本版未执行完整 Release、桌面冒烟或安装；下一完整门槛仍为 rc1840。
