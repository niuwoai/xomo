# Xomo 2.12.0-rc315 测试报告

## 范围

为图层和 UI 组件的变换框增加可拖动参考点。参考点可以位于对象内外，鼠标旋转和菜单旋转共用该支点；移动预览与缩放会带动参考点，Escape、选择切换、Undo/Redo 和默认中心旋转不会留下隐藏支点。

## 验证结果

- 使用共享 DerivedData 完成 macOS 13.0 Debug 测试产品增量编译：通过。
- 参考点默认值、任意位置、移动预览、离中心鼠标旋转、默认中心语义和菜单旋转：5/5 通过。
- 参考点命中、十字准星与变换期间光标稳定性：3/3 通过。
- 旧中心旋转、Shift 15°吸附与 Undo：1/1 通过。
- Escape 取消旋转且不污染 History/Undo：1/1 通过。
- 画布参考点控件与 ViewModel 接线：1/1 通过。
- 中英日本地化键一致性：1/1 通过。
- 定向测试合计：12/12 通过，0 失败。
- 发布契约：3 个测试、7 个断言全部通过。
- 本次为 rc315 小版本，不执行 Release、全量测试、冒烟或 `/Applications` 覆盖安装；下一完整门禁仍为 rc320。

环境：arm64 MacBook Pro、macOS 26.5.2、Xcode 26.4.1。
