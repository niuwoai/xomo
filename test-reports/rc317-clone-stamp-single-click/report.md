# Xomo 2.12.0-rc317 测试报告

## 范围

仿制图章支持单击圆形印章。设置来源点后，单点输入会按当前笔刷直径生成以点击位置为中心的圆形复制蒙版；连续拖动仍使用原有圆头路径，并继续复用对齐偏移、图层采样范围、选区和透明像素锁。

## 验证结果

- 使用共享 DerivedData 完成 macOS 13.0 Debug 测试产品增量编译：通过。
- 单击圆形印章的中心复制、外部像素不受影响与 History：通过。
- 对齐 / 非对齐连续笔画：通过。
- 当前层、当前及以下、所有可见图层采样与 Undo/Redo：通过。
- 跨当前小图层边界采样：通过。
- 选区裁切与透明像素锁：通过。
- 定向测试合计：6/6 通过，0 失败。
- 发布契约：3 个测试、7 个断言全部通过。
- 本次为 rc317 小版本，不执行 Release、全量测试、冒烟或 `/Applications` 覆盖安装；下一完整门禁仍为 rc320。

环境：arm64 MacBook Pro、macOS 26.5.2、Xcode 26.4.1。
