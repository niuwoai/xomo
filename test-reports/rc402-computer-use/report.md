# rc402 Computer Use 工具与滤镜审计报告

- 日期：2026-07-19
- 工具切换：**30/30 通过**
- 组件库模式：通过
- 滤镜菜单：可展开并可准备高斯模糊

逐项点击移动、选区、绘画、修复、取色、文字、形状、路径、抓手和缩放工具后，顶部选中工具值与按钮状态一致。切换到组件库后，内部仍记住上一工具，但画布公开的当前交互为“移动”，不会继续沿用画笔等工具光标语义。

审计发现并在 rc402 修复：油漆桶按钮在修复前没有辅助功能名称，矩形选区主按钮也没有独立工具名称。

后续问题：从滤镜菜单准备滤镜后，右侧滤镜区仍保持折叠，用户需要再次寻找并展开；计划在 rc403 单独修复并继续逐类验证滤镜应用链路。本报告不把“菜单能展开”夸大成“所有滤镜均已完整应用”。
