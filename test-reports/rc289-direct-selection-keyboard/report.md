# rc289 直接选择键盘语义专项回归

- 无实际拖动的直接选择点击不会留下空 Undo
- 直接选择与路径选择共享系统箭头及 `A`/`Shift+A` 工具组

## 交互边界

直接选择状态下，方向键只移动选中的路径节点/控制柄，Delete/Backspace 只删除该节点；不会退化为删除整个路径图层。所有修改都复用现有路径历史和撤销事务。

## 既有失败

更大范围测试仍有预先存在的矢量颜色/路径渲染、布局源码契约和主题 Token 刷新断言失败；这些与本次键盘路由改动无关，已保留在测试输出中。
