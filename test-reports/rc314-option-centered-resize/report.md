# Xomo 2.12.0-rc314 测试报告

## 范围

为图层和 UI 组件的八个缩放控制点增加 Option 从中心缩放，并支持 Shift+Option 中心等比。拖动边吸附到参考线、网格或对象时镜像调整对边，保持原中心；普通缩放、段落文字框、实时尺寸 HUD、Escape 取消、History 与 Undo 保持兼容。
